# 浏览器操作测试

`node frontend/tests/analysis-e2e.cjs` 使用合成数据、18777 端口及临时账本，验证统计报表子页、日/月曲线、分类饼图与一级/二级分类钻取、拆分交易金额、大额门槛按钮、真实分页、收支筛选、原交易详情、空账户组，以及 PC 1280/1920 宽度。期初、转账与撤销不计入收支，部分退款按净支出核对。不会读取或修改正式账本。

`node frontend/tests/sorting-balance-e2e.cjs` 使用合成数据、18776 端口及临时账本，验证交易明细全量跨页排序、退款净额排序、表头/下拉排序同步、筛选回首页，以及资产负债表入口、账户组树、截止日期、合并去重、个人/家庭守恒、期初提示和 PC 布局。不会读取或修改正式账本。

项目已构建前端、已创建 `.venv` 并安装后端依赖时，从项目根目录执行：

```sh
node frontend/tests/e2e.cjs
```

默认使用 macOS `/Applications/Google Chrome.app` 中的 Chrome，可通过 `CHROME_PATH` 指定其他 Chromium 可执行文件，或用 `LEDGER_PYTHON` 指定 Python。需要允许本机端口监听和浏览器启动。

测试自行创建临时数据库、在 `127.0.0.1:18765` 启动测试服务，测试结束关闭服务。不读取或修改正式账本。覆盖账户创建、记账、修改、撤销、主流程上传 CSV、原始记录只读查看、交易明细核对入账、人工确认收入、重复导入、统计图表和窄屏页面。临时目录中保留截图，路径显示在测试结果中。

统一账单与离线分类流程：`node frontend/tests/bills-e2e.cjs`。使用独立临时数据库，覆盖格式转换、分类 JSON 保存、刷新持久化、人工修正及版本历史。


`bills-e2e.cjs` 验证分阶段导入：原文件与统一文件存档、分类文件保存、明确导入明细、重复上传保留批次、流水号去重、重复导入不覆盖人工分类、文件查看下载，以及小荷包独立账户展示。使用独立临时数据库与 18766 端口。


v0.4：`bills-e2e.cjs` 进一步覆盖自动入账、人工核对、单笔撤销、整批撤销、重复批次隔离和余额恢复，共 12 个场景。所有测试撤销使用临时账本，真实账本只进行只读页面验证。

v0.5：统一账单测试新增忽略状态与筛选、忽略记录不转明细、全部忽略无需分类，共 15 个场景。支付宝“不计收支”由来源规则判定，分类文件不能覆盖。


v0.6 私有真实样例端到端测试：设置 `MULTISOURCE_SAMPLES` 为包含 cmb、boc、wechat、pouch 本机路径的 JSON，`MULTISOURCE_CLASSIFIED_DIR` 为对应分类 JSON 目录，然后执行 `node frontend/tests/multisource-e2e.cjs`。使用 18767 端口和临时账本，验证四种格式上传、来源识别、文件存档和明细导入；未提供路径时跳过。原始账单不打包进源码。


v0.7：`node frontend/tests/configuration-e2e.cjs` 使用 18768 端口和临时账本，覆盖账户组层级及分配、合并预览确认、余额与来源映射、来源隐藏、退款候选与 AI 文件保存、成对忽略冲回、单一退款分类、家庭不重复汇总、解除合并、财务平衡和窄屏设置，共 12 个场景。


`processing-e2e.cjs` 验证同付款多次部分退款、净额展示与撤销、原始字段、宽泛分类入账以及数据与设置拆分；使用临时账本和本机测试端口，不改动真实账本。


`associations-e2e.cjs` 在临时账本验证微信与银行凭证关联、LINKED 状态、只保留一笔扣款，以及账户变动与记账分录的展示。


`pagination-e2e.cjs` 使用合成账单和 18772 临时服务，验证六处列表真实翻页、跨页无遗漏和重复、每页条数切换、筛选及批次切换回首页，以及待处理入口与数量。不读取正式账本。


`confirmed-processing-e2e.cjs` 使用 18773 临时服务和合成账单，验证简化参考及退款收入开关保存、重检查入账、三凭证转账幂等、两个实际账户变动，以及退款收入撤销。


`account-groups-e2e.cjs` 使用 18774 临时服务，验证多层账户组、直属账户、父组汇总、合并来源去重、外部账户排除、空组/未分组、选中组添加账户和流水筛选、PC 1280/1440/1920宽度、账户搜索及空结果、更多菜单对账、组配置入口。


`taxonomy-e2e.cjs` 使用18775临时服务验证宝宝一级分类、分类和四级标签的父级筛选、筛选导出、目录参考、新增子分类/子标签、标签编辑/移动及刷新持久化，余额不变。

v0.15：`taxonomy-e2e.cjs` 进一步验证标签整树归档及恢复、历史账单保持不变、归档标签在新选择与 AI 目录中隐藏。`analysis-e2e.cjs` 模拟慢响应，验证点击分类时加载前后保持滚动位置，图表不会卸载。
